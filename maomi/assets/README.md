# RANA cat

`rana_cat.png` is the transparent pixel-art portrait used by RANA Mode's
rotating desktop indicator. It is derived from a photograph of the project
owner's own cat, supplied for this purpose. The original photograph is not
distributed. Runtime code renders the rotation with nearest-neighbor sampling.

Created using the built-in image generation tool on 19 October 2026.

Prompt:

> Create one centered, head-only pixel-art portrait of the owner's fluffy brown
> tabby cat from the supplied reference. Preserve the large greenish amber eyes,
> dark forehead stripes, tan highlights, fluffy cheeks, pale cream muzzle and
> chin, pink-brown nose, tufted ears, and slight head tilt. Remove the photo
> backdrop and body. Use transparent alpha, crisp square pixels, a limited warm
> brown/cream palette, and a dark outline. Keep the whole head visible. No text,
> accessories, extra animals or frame. The application rotates this static head
> and renders its own label beneath it.
